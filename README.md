# Jesus Mission Church Web Application

## Project Overview
The Jesus Mission Church Web Application is a beginner-friendly React project designed
to help church members and visitors access information, announcements, and comments.

## Technologies Used
- React
- React Router DOM
- Tailwind CSS
- JSONPlaceholder API

## Features
- Landing Page
- Members Dashboard
- Comments Section
- Registration Form
- Responsive Design
- Navigation Bar

## Project Structure
src/
components/
pages/
utils/

## API Used
JSONPlaceholder (https://jsonplaceholder.typicode.com)

## Development Process
Week 1: Planning & Wireframing  
Week 2: UI Structure  
Week 3: Forms & API Integration  
Week 4: Dashboard & Responsiveness  
Week 5: Testing & Documentation  

## How to Run the Project
1. npm install
2. npm run dev

## Learning Outcome
This project helped me understand React components, routing, API usage,
and responsive design using Tailwind CSS.
